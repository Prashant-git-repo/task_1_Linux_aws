# Linux Environment Setup & Exploration (AWS EC2)

## 📌 Objective
To gain hands-on experience with Linux system navigation, file management,
permissions, and monitoring tools using an AWS EC2 Ubuntu instance.

## 🖥 Environment
- Cloud Provider: AWS
- Service: EC2
- OS: Ubuntu Server 22.04 LTS
- Instance Type: t2.micro (Free Tier)

## 🔧 Tasks Performed
- Connected to EC2 using SSH
- Explored Linux directory structure
- Created and removed files & directories
- Viewed and edited files using vi editor
- Managed file permissions
- Monitored system resources using top, df, free
